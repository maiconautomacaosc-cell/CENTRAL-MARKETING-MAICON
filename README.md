# Central de Divulgação — v1.0.0
PWA independente da Agenda Maicon Automação.

## Recursos iniciais
- Divulgação do dia
- Biblioteca separada em Fechaduras, Elétrica e Móveis
- Texto pronto editável
- Arte quadrada gerada no próprio navegador
- Copiar texto, salvar arte e compartilhar
- Controle diário dos grupos onde já publicou
- Histórico local de divulgações
- Instalável como PWA

## Publicação
Envie estes arquivos para a raiz de um repositório GitHub e habilite GitHub Pages.
